Aplicação que serve como um centro de distribuição de arquivos, assim como um servidor FTP, mas aceitando diversos protocolos, entre eles:
- FTP
- FTPS
- SFTP
- HTTP
- HTTPS
- WebDAV

Disponibiliza interface web via browser, permitidno a gestão dos arquivos, transferencias e partilhas de arquivos por parte dos usuários.

Suporte para automação e integração com diretórios corporativos como AD, LDAP ou servidores SQL. 

#### Segurança
As pastas `/crushftp` e `/webinterface` são alvos após o acesso inicial para se instalar web shells e payloads
