Uma vulnerabilidade é uma falha em hardware ou software, potencialmente explorável por atacantes, por exemplo:
-  Um servidor SSH que a partir de uma requisição mal formada permite com que o atacante faça login como root
-  Um site Wordpress que usa um plugin que permite **RCE**
-  Sistemas operacional Windows 7 que permite a partir de pacotes mal-formados obter controle sobre o SMB

Vulnerabilidades sempre existirão visto que nenhum sistema é 100% seguro nem nunca será, todos os dias são descobertas novas vulnerabilidades, de diversas formas diferentes:
- [[Grupos de Cybercrime]] desenvolvendo vulnerabilidades para o uso malicioso.
- [[Pesquisadores de Cybersegurança]] pesquisando sobre possiveis falhas de software
- Profissionais de [[RedTeam]] realizando pentests

Por ser um conceito amplamente usado em toda área de TI surgiram padrões de nomeação de vulnerabilidades, entre eles as [[CVE]]s. Esses são os padrões para as vulnerabilidades conhecidas, porém quando uma vulnerabilidade foi descoberta mas ainda não foi catalogada o termo em que é chamada é [[Zero Day]], o nome faz referencia a vulnerabilidade ter sido catalogada à 0 dias, ou seja que ainda não foi descoberta.
